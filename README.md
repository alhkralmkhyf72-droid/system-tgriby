# نظام تسجيل الرغبات – كلية الزراعة جامعة الفيوم

مشروع جاهز للرفع على GitHub Pages، مرتبط بـ Firebase، ويستخدم Google Apps Script لإرسال إشعارات اعتماد الطلاب من بريد الوحدة إلى المرشد الأكاديمي.

## محتويات المشروع
- `index.html`: واجهة الطالب.
- `admin.html`: لوحة الإدارة.
- `setup-admin.html`: إنشاء حساب المدير لأول مرة فقط.
- `firebase.js` و`logic.js`: إعداد Firebase ومعالجة ملفات Excel.
- `firestore.rules`: قواعد حماية Firestore.
- `functions/`: وظائف Firebase لحذف حسابات الطلاب وإرسال إشعار اعتماد الاستمارة.
- `send-advisor-emails.gs`: Google Apps Script الذي يرسل البريد من حساب الوحدة.
- `قالب_المرشدين.xlsx`: قالب ملف المرشدين الشامل، بورقتين.
- `students-template.xlsx` و`catalog-template.xlsx`: قوالب الطلاب والرغبات.

> لا ترفع ملفات البيانات الفعلية للطلاب أو أرقامهم القومية أو الإيميلات الشخصية إلى مستودع GitHub عام. المشروع المضغوط يحتوي على قوالب فارغة فقط.

## 1) رفع المشروع على GitHub
1. فك ضغط ملف المشروع.
2. افتح المجلد `agri-desires-project`.
3. ارفع **كل محتويات هذا المجلد** إلى جذر مستودع GitHub، وليس ملف ZIP نفسه.
4. من `Settings > Pages` اختر النشر من الفرع `main` والمجلد `/ (root)`.
5. بعد النشر افتح رابط الموقع.

## 2) ملفات Excel الثلاثة التي ترفعها من لوحة التحكم
من تبويب «الملفات» توجد ثلاثة اختيارات فقط:

1. **ملف الطلاب**: ورقة واحدة، الأعمدة `الكود | الاسم`.
2. **ملف المرشدين الأكاديميين**: ملف واحد شامل، ويقبل أحد الشكلين:
   - ورقة واحدة بالأعمدة `المرشد | القسم | Gmail | اسم الطالب` (مثل ملف المرشدين الأصلي؛ تتكرر بيانات المرشد مع كل طالب تابع له).
   - أو ورقتان: `بيانات المرشدين` بالأعمدة `المرشد | القسم | Gmail`، و`توزيع الطلاب` بالأعمدة `المرشد | اسم الطالب`.
   يتم استخراج اسم المرشد والقسم وبريده من هذا الملف نفسه، وربط كل طالب بمرشده.
3. **ملف الرغبات**: ثلاث أوراق بالترتيب: `البرامج`، `مقررات البرامج`، `المقررات الاختيارية`.

يمكن إضافة مرشد يدويًا من تبويب «المرشدون» بكتابة الاسم واللقب والقسم وبريد Gmail. البريد والقسم مطلوبان حتى يعمل الإشعار الآلي.

## 3) إعداد Firebase
المشروع يستخدم Firebase project: `system-desires` كما هو محدد في `firebase.js`.
1. فعّل Authentication باستخدام Email/Password.
2. أنشئ Firestore Database.
3. ثبّت Firebase CLI وسجّل الدخول.
4. من جذر المشروع انشر القواعد: `firebase deploy --only firestore:rules`.
5. افتح `setup-admin.html` مرة واحدة لإنشاء حساب المدير، ثم احذف الصفحة من الاستضافة أو امنع الوصول إليها بعد إنشاء المدير.

## 4) إعداد إرسال البريد تلقائيًا عند اعتماد الطالب
عند ضغط الطالب «اعتماد وطباعة» وحفظ الاستمارة بنجاح:
- ترسل الوظيفة إشعارًا إلى بريد الوحدة الرئيسي.
- يرسل بريد الوحدة رسالة بتفاصيل الطالب ورغباته إلى البريد الشخصي للمرشد المسجل في ملف المرشدين، مع نسخة إلى بريد الوحدة.
- يظهر اسم المرشد والقسم في الاستمارة المطبوعة.

### أ) تجهيز Google Apps Script
1. افتح `send-advisor-emails.gs` في `script.google.com` والصق محتواه.
2. في السطر **7** غيّر `SENDER_EMAIL` إلى بريد Gmail الرسمي للوحدة، وهو الحساب الذي ستنشر منه السكريبت.
3. في السطر **8** غيّر `MAIL_TOKEN` إلى رمز طويل وعشوائي.
4. اختر `Deploy > New deployment > Web app`.
5. اختر `Execute as: Me` و`Who has access: Anyone` ثم Deploy ووافق على صلاحية إرسال البريد.
6. انسخ رابط النشر الذي ينتهي بـ `/exec`.

### ب) ضبط أسرار Firebase Functions
من الطرفية داخل مجلد المشروع نفّذ الأوامر التالية، وأدخل القيم عند طلبها:

```bash
firebase functions:secrets:set APP_SCRIPT_URL
firebase functions:secrets:set APP_SCRIPT_TOKEN
firebase functions:secrets:set UNIT_EMAIL
```

- `APP_SCRIPT_URL`: رابط Web App الذي ينتهي بـ `/exec`.
- `APP_SCRIPT_TOKEN`: نفس الرمز الذي وضعته في `MAIL_TOKEN` داخل Apps Script.
- `UNIT_EMAIL`: بريد الوحدة نفسه الذي وضعته في `SENDER_EMAIL`.

ثم انشر الوظيفتين:

```bash
firebase deploy --only functions
```

قد يتطلب نشر Cloud Functions تفعيل خطة Blaze في Firebase/Google Cloud. لا تضع رابط السكريبت أو رمز الحماية داخل ملفات HTML أو JavaScript العامة.

## 5) الحفظ والاعتماد والطباعة
- زر «حفظ» يعرض رسالة: «تم حفظ رغباتك ويمكنك التعديل عليها مرة أخرى»، ويظل بإمكان الطالب تعديل رغباته.
- زر «اعتماد وطباعة» يفتح نافذة تأكيد توضح أن الاعتماد سيقفل الاستمارة ولا يمكن تعديلها بعد ذلك إلا عن طريق الإدارة.
- بعد الموافقة تُحفظ الاستمارة بحالة معتمدة ومقفلة، ثم تظهر نافذة الطباعة.
- في أسفل الاستمارة يظهر اسم المرشد الأكاديمي والقسم.
- إذا فشل البريد لأي سبب، يظل اعتماد الاستمارة محفوظًا ولا تتعطل الطباعة؛ يظهر تنبيه للطالب ويجب مراجعة سجل Firebase/Logs أو بريد الوحدة.

## 6) حذف حسابات الطلاب المسجلين
زر «مسح بيانات الطلاب المسجلين وحساباتهم» يستدعي Cloud Function تحذف حسابات Firebase Authentication ووثائق `users` و`claims` فقط. لا تحذف:
- ملف الطلاب (كشف الأسماء والأكواد).
- توزيع الطلاب على المرشدين وبيانات المرشدين وإيميلاتهم.
- البرامج والمقررات والرغبات.
- الشعارات وبيانات الهوية.
- حسابات الإدارة.

## 7) الطباعة والنسخ الاحتياطي
- زر PDF يفتح نافذة الطباعة؛ اختر «حفظ كملف PDF».
- تصدير Excel يستخدم SheetJS مع تنزيل Blob لدعم الهواتف.
- اختبر التسجيل والحفظ والاعتماد والبريد والحذف بحسابات تجريبية قبل التشغيل الفعلي.
